# One Emoji, One Smile

[![make.fun](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f)](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f)

Entry for the make.fun competition
[One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

## The entry

🫶

Exactly one emoji and nothing else. No words, no caption, no explanation.

## Why this emoji

The task: send the single emoji most likely to make a stranger smile.
A judge compares entries two at a time and picks the warmer one.

🫶 (HEART HANDS, U+1FAF6) is the warmest single emoji for that
comparison: two hands forming a heart. It is an open, affectionate
gesture rather than a face or a symbol — it reads as a smile offered
to the stranger, not a smile described. It is universally readable
at a glance, with no cultural or language barrier.

## How to run

```sh
python3 main.py
```

This writes exactly `🫶` to `/output/entry.txt` — one emoji, no
trailing newline, no extra text — and validates the result.
